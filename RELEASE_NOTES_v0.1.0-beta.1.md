# v0.1.0-beta.1

> Первый публичный выпуск панели-администрирования. Beta: управляющие действия
> частично в режиме чтения.

## Возможности

- живой дашборд поверх собственных баз бота (операции сегодня, средний ответ
  API, требуют внимания, заведено по каналам);
- очередь обработки с действием «Отменить» (только не-созданные заявки
  `preview` / `needs_clarification`);
- статус-лампочки транспорта и сервисов (Official API, Playwright fallback,
  Telegram intake, Mail watcher, AI analyzer);
- журнал событий и диаграмма операций по источникам;
- разделы «Подключение» (IntraService / Telegram) и «Доступ» (ФИО + Telegram ID);
- четыре темы (Aurora, светлая, тёмная, минимализм);
- маршрутизация по хэшу: у каждой страницы свой адрес, переживает перезагрузку
  и работает «назад/вперёд»;
- локальная сессионная авторизация со scrypt-паролем, CSRF и rate-limit.

## Установка

```bash
git fetch --tags
git switch --detach v0.1.0-beta.1
npm install
npm run bootstrap-admin
npm run ci
```

Перед обновлением сделайте резервную копию `data/auth.json` и баз бота. Не
коммитьте секреты, SQLite и профили.

Панель — отдельный модуль рядом с ботом; путь к базе задаётся переменной
`PANEL_BOT_DIR` (по умолчанию `../intraservice-server-bot`). См.
[README.md](README.md).

## Ограничения beta

- настройка подключения и управление доступом в публичной версии — режим
  чтения (запись выполняется самим ботом);
- панель не подключается к IntraService и не выполняет мутации заявок;
- единственное исключение — явная отмена заявки из очереди, повторяющая
  запросы самого бота;
- токен и пароль бота читаются только замаскированно и никогда не выводятся.
