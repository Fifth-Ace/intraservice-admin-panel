# v0.2.0 — Community Edition

Стабильное обновление веб-панели для
[IntraService Telegram Bot](https://github.com/Fifth-Ace/intraservice-telegram-bot).

## Главное

- переработанный dashboard без декоративных и выдуманных событий;
- четыре компактных KPI и отдельная сводка создания заявок по каналам;
- реальные состояния intake, mail watcher, AI analyzers и планировщика из
  `systemd`;
- исправлена навигация: автообновление больше не показывает главную страницу
  поверх открытой вкладки;
- корректная метрика API: среднее только по успешным `api_primary_read` за
  скользящие 24 часа с количеством замеров;
- безопасное управление подключением IntraService, двумя Telegram-контурами и
  proxy;
- управление whitelist пользователей Telegram-бота;
- цепочка изменения настроек:
  `preview → подтверждение → backup → атомарная запись → restart → проверка`;
- пустые поля пароля/токена сохраняют существующие секреты;
- optimistic revision блокирует запись из устаревшей вкладки;
- локальные backup-копии защищены правами `0600`;
- публичная Community Edition оставляет запись конфигурации выключенной по
  умолчанию (`PANEL_ENABLE_CONFIG_WRITE=0`).

## Обновление

```bash
git fetch --tags
git switch --detach v0.2.0
npm install
npm run ci
```

Существующий `data/auth.json` не перезаписывайте. Для новой установки отдельно
запустите `npm run bootstrap-admin`.

## Проверка

```text
npm run check
npm test
```

Self-tests проверяют авторизацию, CSRF, сохранение старых секретов, атомарную
запись, права `0600`, управление доступом и блокировку устаревшей revision.
Тесты не создают и не изменяют заявки IntraService.

## Граница безопасности

Панель не выполняет мутации заявок IntraService. Единственное действие над
очередью — явная отмена ещё не созданной заявки. Запись config/env является
opt-in, ограничена известными файлами и требует авторизованной HTTPS-сессии,
CSRF, предпросмотра и подтверждения.
