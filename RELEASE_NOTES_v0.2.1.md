# v0.2.1 — Dashboard preferences hotfix

Исправление регрессии переключателей блоков главной страницы.

## Исправлено

- первый клик по одному переключателю больше не скрывает остальные блоки;
- каждый переключатель изменяет только свой модуль;
- предпочтения всегда сохраняются полным набором из пяти ключей;
- повреждённое хранилище `panel-dash-v1` автоматически игнорируется;
- новая схема `panel-dash-v2` восстанавливает все блоки главной по умолчанию;
- подписи переключателей теперь честные: `Вкл` / `Выкл`;
- автообновление не показывает главную страницу поверх открытых вкладок.

## Проверка

В browser-regression последовательно проверены KPI, каналы, очередь, диаграмма и
сервисы: отключение одного блока не меняет видимость остальных. Все маршруты
сохраняют ровно одну активную страницу после принудительного `render()`.

```bash
npm install
npm run ci
```

Обновление не изменяет конфигурацию бота, секреты, базы и заявки IntraService.
